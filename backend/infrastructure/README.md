# Infraestructura

Esta carpeta contiene la configuración local de PostgreSQL y Redis administrada
por `docker-compose.yml` en la raíz de `backend`. No contiene tablas,
migraciones, credenciales ni configuración específica de producción.

Consulta [`../docs/DOCKER_INFRASTRUCTURE.md`](../docs/DOCKER_INFRASTRUCTURE.md)
para los comandos de operación, diagnóstico y las recomendaciones de seguridad.
